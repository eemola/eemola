## Selected projects

Part of [Machine-Learning-Projects](https://github.com/eemola/Machine-Learning-Projects): applied machine learning in R, built on real housing listings from Cali.

| Project | What it does | Result |
|---|---|---|
| [**Housing price prediction**](https://github.com/eemola/Machine-Learning-Projects/tree/main/01-housing-price-prediction) | Predicts the price of a home from its listing, comparing linear models, Ridge / Lasso / Elastic Net and k-NN under spatial cross-validation | RMSE of COP 181.8 million, R² 0.71, 47% less error than the mean |
| [**Social-housing (VIS) classification**](https://github.com/eemola/Machine-Learning-Projects/tree/main/02-vis-classification) | Finds subsidized-housing listings, a rare class (5%), with a threshold chosen from the cost of each error | AUC 0.94; 91% recall at the cost-optimal threshold |
